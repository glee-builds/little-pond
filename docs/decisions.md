# Decisions log

Every project decision, when it was made, and why. When a decision changes, don't delete the old row: mark it as replaced and add a new row explaining what changed and why.

| Date | Area | Decision | Reason |
|---|---|---|---|
| 2026-11-26 | Code | Plain HTML, CSS, JavaScript ES modules. No framework, no build step | Every file stays readable for a beginner |
| 2026-11-26 | Workflow | After the first commit, never commit directly to `main`; every change goes through a branch and a pull request | Gives the owner a review step before anything reaches `main` |
| 2026-11-26 | Shape | A separate app from Lily Pad, not a mode inside it | Lily Pad's screens assume a reader; a separate app can't break it |
| 2026-11-26 | Balance | Mostly number sense, with a few sound and word games | The owner's call |
| 2026-11-26 | Adding | Taught by joining groups and by splitting a group in different ways, not as written sums | Ideas the player can see and handle, not memorized facts |
| 2026-11-26 | Repo and hosting | Public repo `little-pond`, GitHub Pages from `main` | Free hosting; nothing in the repo describes a person |
| 2026-11-26 | Reuse | Copy and trim Lily Pad's shared files instead of linking to them | Two repos with no build step cannot share files |
| 2026-11-26 | Daily set | "Today's 4": 3 number games and 1 sound game (4 number games until the sound games exist) | About 5 minutes |
| 2026-11-26 | Rounds | 4 rounds per game. The third miss shows the answer and moves on | Short and kind |
| 2026-11-26 | Pond | One frog hop per day played. Days in a row show only on the grown-up page | No streak pressure for a young player |
| 2026-11-26 | Instructions | Spoken by the device's built-in voice, with a speaker button to hear it again | Nothing has to be read; no network request |
| 2026-11-26 | Letter sounds | Recorded by a grown-up on the grown-up page; kept on the phone, never in the repo | The built-in voice can't say single sounds, and a voice recording is personal |
| 2026-11-26 | Grown-up page | Opened by holding the link for 2 seconds | Keeps "Start over" out of a young player's reach |
| 2026-11-26 | Tap to count | Tapping a frog says the next number and marks it. Never a miss or a hint | Counting is the method |
| 2026-11-26 | Open rounds | Rounds with several right answers accept any correct arrangement | They are about finding a way, not the way |
| 2026-11-26 | Character and icon | The app's character is a duckling, and the icon is the duckling on a lily pad at sunrise. Number games count ducklings | The owner asked for a different character and icon from Lily Pad's frog, in a similar style, so the two apps are easy to tell apart |
| 2026-11-26 | Shell | Home screen, pond, today's set, earlier days, sticker book, grown-up page, Refresh, and offline play are copied from Lily Pad and trimmed: no "how to play" cards, weekly note, or review lists | Those rely on reading, or on games this app doesn't have |
| 2026-11-26 | Today's set while there are few games | The set is up to 4 games; with fewer games than that, it is every game there is | The app ships one game at a time |
| 2026-11-26 | playRounds | One helper in `src/scene.js` runs every game's rounds: the spoken line, the speaker button, round dots, misses, showing the answer after the third miss, and the player's place | Keeps each game to one short file |
| 2026-11-26 | How Many | First game. Ducklings on a lily pad; pick the card with the same number of dots. Levels: 1 to 3, 1 to 5, 4 to 10. Never the same number twice in a row; the two wrong cards are within 2 of the right one | Seeing a small amount at a glance |
| 2026-11-26 | Scene, for now | (Replaced 2026-11-27: see "Scene".) `src/scene.js` has no drag-or-tap yet; it arrives with Groups, the first game that drags | Nothing uses it yet |
| 2026-11-26 | No voice | If the device has no English voice stored on it, the home screen says so to a grown-up. The games still open | The app should say why it is silent |
| 2026-11-27 | How Many counts first (replaces "Tap to count" being optional there) | The player taps each duckling and the app counts up aloud with every tap. The answer cards are faded and can't be tapped until the last duckling is counted; then the app asks "How many ducklings?" Ducklings still to count bob a little | The owner wants the player to count each one, with the app counting along, before answering |
| 2026-11-27 | Workflow | The 12 games after How Many were added together, on one branch (replaces "each game is its own pull request" for this batch; the rule stands for later games) | The owner asked for all the games at once |
| 2026-11-27 | Game files | Each game is `src/games/<name>.js` with its styles in `src/games/<name>.css` beside it, loaded when the game is first opened. A game registers itself: its file exports `meta` (title, group, levels, card picture, whether it has a `.css` file), and its name is added to `NAMES` in `src/games/index.js`. `src/app.js` has no list of games | Games can be written and changed without touching a shared file |
| 2026-11-27 | Scene | After the games were written, the pieces two or more of them share moved into `src/scene.js` and `styles.css`: answer cards that can sleep (`dotCards`, `pictureCards`), the numbers for 3 close choices, the round check button, the bank of ducklings to move onto pads, drag-or-tap, rows of 5, a faded "gone away" duckling, and one check mark for a right answer. `range` is in `src/ui.js`. A game's `.css` file keeps only what that game alone needs | The games were written separately and repeated each other; one copy of each piece is easier to read and to fix |
| 2026-11-27 | Always light | The app always has a light background and does not follow the device's dark mode. The dark palette copied from Lily Pad was removed; `color-scheme: light` is set in `styles.css` and `index.html` | The owner asked for a light background always |
| 2026-11-27 | Old iPads | The app must run on Safari 15.4. `color-mix()` (Safari 16.2) is used only inside `@supports`, with plain colors for older browsers | The player may use an older iPad |
| 2026-11-27 | Groups | As planned (2 pads, 3 pads, fair sharing between 2 or 3 pads, never more than 10 ducklings). Added: a round check button that wakes up once every duckling is on a pad | A half-done round should never be a miss |
| 2026-11-27 | Join | Levels 1 and 2 as planned (to 5, to 10): push the pads together, then pick how many in all. The splitting level departs from the plan: the group is 5 to 10 ducklings (not always 5), a different size every round, and any split that leaves neither pad empty is right | A different group each round means no split comes up twice in a day, without the game having to remember earlier answers |
| 2026-11-27 | Hop Away | 3 levels, not the planned 2: start with 2 to 5; start with 4 to 10 and 1 to 3 hop away; start with 4 to 10 and 3 or more hop away, sometimes leaving none. The player presses a big go button to start the hop, and the ducklings that left stay in view, faded | A third level reaches zero; pressing go makes the player the one who causes the change |
| 2026-11-27 | One More, One Less | 3 levels, not the planned 2: one more only (to 5); one more and one less (to 5); both (to 10). The cards are always the starting number and its two neighbours | One more is easier than one less, so it comes alone first |
| 2026-11-27 | More or Fewer | As planned: differ by 2 or more (to 6), differ by 1 (to 10), make the same (1 to 3 apart). "Make the same" has an add button, a tap sends a duckling away, and a check button | The player decides when the pads match |
| 2026-11-27 | Sort | Departs from the plan (big or small, then by color with a shape mark, then by two things). Level 1: big and small ducklings. Level 2: two kinds of pond animal (duckling, fish, frog, bug). Level 3: three kinds. A thing dropped on the wrong pad is a miss and stays where it was | Kinds of animal differ in shape, not only in color, and are easier to tell apart on a small screen |
| 2026-11-27 | Order | As planned (3, 4, 5 ducklings). Added: the top level sometimes asks for biggest first; dots under the spots, small to big, show which end is which; the line is checked by itself when the log is full, and any in the wrong spot go back to wait | No check button is needed, and a full log is always a fresh try |
| 2026-11-27 | Patterns | As planned (AB; AAB and ABB; ABC), with pond things (duckling, flower, fish, dragonfly, snail) in place of frog and fly. Level 1 has 2 cards, the others 3; at level 2 one card is not in the pattern at all | Things that differ in shape as well as color |
| 2026-11-27 | Match the Number | As planned (to 3, to 5, to 10). Added: at the top level the other two pads are within 2 of the answer, and ducklings on any pad can be tapped to count | Close amounts have to be counted, not guessed |
| 2026-11-27 | Shapes | As planned (circle, square, triangle; then rectangle and star in different sizes; then turned and stretched). Colors are random and can repeat, so color never tells the answer. Circles and squares are never stretched | A stretched square would be a different shape |
| 2026-11-27 | Slide | As planned, with a duckling on a track in place of a slider; a tap on the duckling hops it to the next letter. Level 1 plays stretchy words first, and its wrong pictures start with a different letter; a wrong picture is never one the player might call by the right word | Sliding and tapping both work; the first sound alone can settle an early round |
| 2026-11-27 | Sounds | As planned (2 pictures, then 3). The voice says "Which one starts with" and the recording follows; a big duckling says the sound again.
